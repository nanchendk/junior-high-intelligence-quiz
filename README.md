# 國中新生智力測驗模擬題庫

這是一個可直接部署到 GitHub Pages 的靜態網站。

## 功能

- 30 題模擬題
- 語文、數量、圖形與空間推理
- 25 分鐘倒數計時
- 自動計分
- 分項成績
- 錯題與完整解析
- 手機、平板與電腦自動排版
- 不需後端或資料庫

## 使用方法

直接用瀏覽器開啟 `index.html` 即可測試。

## GitHub Pages

將 `index.html` 放在儲存庫根目錄，再到：

Settings → Pages → Build and deployment → Source: Deploy from a branch

選擇：

- Branch: `main`
- Folder: `/ (root)`

儲存後即可發布。
